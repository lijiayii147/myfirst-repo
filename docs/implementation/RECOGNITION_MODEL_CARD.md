# 母题识别模型说明 · v0.2

## 任务与实现

任务：对有清晰前景的平面纹样，检索用户标注的母题参考类别。默认示例类别为花卉、鸟、鱼、几何；真实图库允许自定义中文类别。没有对年代、地域、真伪、文化寓意或具体传承体系进行自动识别。

方法：前景外接框裁剪，等比例缩放并居中，24×24前景网格、4×4局部梯度方向直方图与水平／垂直投影组合为特征；分块归一化后按0.65／0.25／0.10加权。类别分数为该类别中最高的参考样本余弦相似度。这是参考检索基线，不是深度网络，也没有把程序图案称为真实非遗训练样本。

输出：候选类别、分数、参考编号与来源、类别差距、未知状态、构图的镜像IoU描述。默认至少两个参考类别，最高相似度≥0.82且与第二类别差距≥0.035时才返回确定标签。阈值为原型设置，未针对真实非遗验证集校准；分数不是概率。

## 数据与同意

- 真实识别图库默认空白，需要使用者导入有权使用且标注可靠的参考图片，并单独确认用于本地参考识别。
- 内置80幅演示参考来自原创程序：4类别×20种子，没有第三方馆藏图片。
- 演示图库和真实图库通过API参数显式区分，演示图不自动混入真实图库；后端拒绝直接将内置合成资产加入用户参考图库。
- 上传者自行上传的合成图或错误标注不能由程序可靠检测，仍需人工管理。
- 识别排除当前资产本身；正式评估仍需按原作分组，避免同一原作不同上传或裁剪引起泄漏。

## 评估

`recognition_evaluation.json`报告40幅合成验证输入与80幅合成测试输入。参考、验证、测试种子不同，但共享同一程序模板。结果只能用于检查代码是否按预期工作，不能估计真实非遗准确率、跨地域泛化或工艺识别能力。

目前没有合法、专家标注、按原作分组的真实非遗训练／验证／测试数据集。因此不提供真实非遗准确率承诺。数据库中28条博物馆元数据不是图像训练集。

## 已知限制与下一阶段

复杂照片、纹理背景、拍摄倾斜、较大旋转、遮挡、断裂与细节密集的图像可能二值化失败或匹配错误；某些花鸟组合也不适合单标签分类。返回未知不意味着纹样不属于该类别，返回匹配也不构成文化事实证明。

建议先以每类5—10幅独立原作建立试用参考库，并记录错误；正式研发应进一步扩大合法数据，支持多标签和局部检测，按原作划分数据，在验证集标定阈值，并比较预训练视觉编码器。即使接入通用图像模型，仍需真实文化纹样验证。

预训练资源检查：Hugging Face模型接口在本次环境中返回代理403；PyTorch官方MobileNet权重地址可访问，但本版本没有下载或使用该权重，不能将官方通用模型性能归于本系统。
